# Apartment Escape Game

A browser game inspired by the uploaded apartment/floor-plan image.

## Game
You are inside the apartment. Find **3 keys** hidden in the bedrooms and bathroom, avoid the moving security bot, and reach the front door before the 120-second timer ends.

### Controls
- **WASD / Arrow Keys** — move
- **R** — restart
- **Restart button** — restart the game

## Run
Open `index.html` in a browser. No build tools or external libraries are required.

## Layout
The game recreates the main visual structure of the reference:
- Kitchen and dining area on the left
- Central living room with sofa/TV
- Bedrooms across the top and lower-right
- Bathroom on the right
- Front exit at the lower-right
